# nf-genome_to_diffraction v0.1.0

Release date: 2026-08-19

## Release type

This is an archival, incomplete research-prototype release. It preserves the
single-component baseline before the project pivots to prototype-first
two-component heteromer development.

It is not a production release, an automated protein-identity claim, or an M6
scientifically validated release.

## Included

- trusted protein-catalogue import and exact sequence grouping;
- MTZ preflight, SDS-PAGE/Matthews candidate-copy hypotheses, and retained
  physical-prior evidence;
- local PDB sequence and ProstT5/Foldseek discovery plus exact AFDB retrieval;
- predicted and experimental MR model preparation;
- first-copy Phaser screening and human MR-seed review;
- sequential same-component copy placement;
- brief refinement, maps, sequence-from-map scoring, and a second review
  checkpoint;
- typed provider plans and enabled/disabled provider routing;
- reproducible Pixi/Nextflow environment and reviewed Marmic execution wrapper;
  and
- preserved M0--M5 and control evidence.

## Known limitations

- M6 scientific acceptance is held. Marmic Slurm run `629614` demonstrated
  Nextflow/Slurm fan-out and cache behaviour only.
- Heteromer `nA + mB` reconstruction is not implemented.
- The 7L6G control placed three copies rather than its declared six.
- Same-component copy placement in the released path remains sequential rather
  than a complete joint-copy search.
- Space-group/resolution propagation, Free-R membership identity, parent
  uncertainty/support semantics, transactional output handling, final
  Rwork/Rfree parsing, and sequence-map failure classification remain
  incomplete.
- Some raw-input/cache invalidation, network-site, retry, and M6 measurement
  hardening remains deferred.
- The three unknown operator crystals have not been used for validation and
  remain exploratory inputs.

## Scientific interpretation

All reported structures and sequence rankings are review candidates. Packing,
LLG, TFZ, Matthews probability, SDS-PAGE compatibility, model confidence, and
sequence-from-map scores are evidence fields rather than proof of identity or
composition.

## Next development target

v0.2 begins with a minimal real Phenix control: fix a reviewed A solution and
search one B component for 6RTZ HisF/HisH. After that works, extend to
end-to-end 6RTZ, explicit `nA + mB`, and a small positive/negative control
slice. The former M6/R2--R4 hardening programme is deferred until after the
working heteromer prototype unless a known control demonstrates a blocking
scientific defect.

Stage 07

Reviewed report and evidence package

Assemble checksummed results that distinguish supported findings, ambiguity, no-hit, provisional depth, held status, and execution failure.

Current maturity: implemented; deeper private analysis not authorised

Visible limitation. Visible implementation is not run authorisation: required review evidence is still incomplete.

Purpose

Publish a portable, auditable conclusion whose strength never exceeds the reviewed evidence.

Inputs

  • All owned stage outputs and raw metrics
  • Final sequence and composition decisions
  • Execution, environment, database, and checksum manifests

Outputs

  • Reviewed narrative report
  • Machine-readable statuses and scope decisions
  • Immutable evidence and resource summary

Decisions and statuses

  • Refuse claims when required review or source records are absent
  • Keep scientific status separate from execution status
  • Publish no-hit and ambiguity as valid completed analyses

Claim and failure boundaries

  • Models remain hypotheses unless supported by diffraction and review
  • Exact locus identity is withheld when the map cannot discriminate it
  • Deeper private analysis remains blocked until every required review gate is complete
Run commands and implementation links

Use commands only with the reviewed configuration, immutable source, and owned inputs for the intended site. Placeholders are deliberate.

Stage 02

Crystallographic preflight

Select observations, symmetry, resolution, anisotropy, Patterson evidence, and Free-R authority before scheduling molecular replacement.

Current maturity: locally tested

Visible limitation. Qualification and runtime checks exist; fixed-profile evidence remains source- and site-specific.

Purpose

Decide whether each diffraction dataset is qualified to proceed, must be held for review, or is invalid.

Inputs

  • Owned MTZ and crystal identifier
  • Operator crystallographic declarations
  • Installed Phenix runtime manifest

Outputs

  • Diffraction selection and Free-R identity
  • Review package with proceed or hold decision
  • Raw preflight and Xtriage evidence

Decisions and statuses

  • Proceed only from an authenticated file-based review
  • Retain a review hold as a valid completed outcome
  • Fail on inconsistent symmetry, observations, or Free-R identity

Claim and failure boundaries

  • Preflight qualifies data; it does not identify a protein
  • A hold schedules no downstream molecular replacement
  • Phenix is an external licensed runtime and is never installed by the workflow
Operator commands and implementation links

Use commands only with the reviewed configuration, immutable source, and owned inputs for the intended site. Placeholders are deliberate.

pixi run -e hpc nextflow run qualification.nf --operation mtz_preflight -stub-run

Documentation / Workflow stage
Stage 02

Crystallographic preflight

Select observations, symmetry, resolution, anisotropy, Patterson evidence, and the exact Free-R source before model discovery.

Current maturity: locally tested

Visible limitation. Preflight and model discovery are shown sequentially; implementation-level file contracts remain in the developer view.

Purpose

Qualify each diffraction dataset before the workflow proceeds to model discovery.

Inputs

  • Owned MTZ and crystal identifier
  • User-provided crystallographic declarations
  • Installed Phenix runtime manifest

Outputs

  • Diffraction selection and Free-R identity
  • Machine-readable qualification result
  • Raw preflight and Xtriage evidence

Decisions and statuses

  • Continue to model discovery with qualified diffraction data
  • Retain non-fatal warnings for later review
  • Fail on a missing usable observation selection or another fatal diffraction-data condition

Claim and failure boundaries

  • Preflight qualifies data; it does not identify a protein
  • The scientist overview shows no interactive pause between preflight and model discovery
  • Phenix is an external licensed runtime and is never installed by the workflow
Run commands and implementation links

Use commands only with the reviewed configuration, immutable source, and owned inputs for the intended site. Placeholders are deliberate.

pixi run -e hpc nextflow run qualification.nf --operation mtz_preflight -stub-run
nf-gtd-hpc-test review-collect --run-id RUN_ID

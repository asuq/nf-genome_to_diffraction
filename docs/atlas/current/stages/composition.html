Documentation / Workflow stage
Stage 06

Bounded composition expansion

Expand reviewed states through B-F hypotheses with explicit depth, beam, attempt, and review boundaries.

Current maturity: scientifically validated to depth three

Visible limitation. Depths 4-6 remain visible but unvalidated and cannot support a complete-composition claim.

Purpose

Test whether additional catalogue components explain residual content without turning search exhaustion into a complete-composition claim.

Inputs

  • Reviewed A state or authenticated no-A continuation
  • All-eligible model registry
  • Parent-bound depth plan and operator composition decisions

Outputs

  • Per-depth attempt inventories and retained parent states
  • Component scope decisions
  • Claim-free terminal composition and sequence review packages

Decisions and statuses

  • Retain at most three parent states per depth
  • Bound work to 25 attempts per depth and 100 additional-component attempts per crystal
  • Stop on depth, budget, no-model, needs-review status, or no residual content

Claim and failure boundaries

  • Depth three is positively qualified by 9ECN
  • Depths four through six are always provisional
  • No automatic identity or complete-composition claim is made between depths
Operator commands and implementation links

Use commands only with the reviewed configuration, immutable source, and owned inputs for the intended site. Placeholders are deliberate.

pixi run --locked phase3-composition-beam-stub

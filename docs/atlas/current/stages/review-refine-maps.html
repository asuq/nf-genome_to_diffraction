Stage 05

Review, refine, and read maps

Authenticate the A-seed decision, refine retained states, inspect maps, and narrow identity only as far as the evidence supports.

Current maturity: locally tested

Visible limitation. Real Phenix and fixed-HPC qualification remain incomplete for some paths.

Purpose

Turn machine-ranked placements into human-reviewed structural states with explicit claim and abstention boundaries.

Inputs

  • Owned first-copy evidence package
  • File-based A-seed decision
  • Qualified diffraction and Free-R identities

Outputs

  • Approved, rejected, or deferred seed state
  • Refinement metrics and maps
  • Sequence and component review packages

Decisions and statuses

  • Resolve decisions only through the registered review package
  • Accept ambiguity or abstention
  • Separate malformed output from a scientific no-hit

Claim and failure boundaries

  • Map support may be insufficient to distinguish paralogues or loci
  • Rwork/Rfree and map-model fit must remain visible
  • A review decision cannot invent an unregistered state
Operator commands and implementation links

Use commands only with the reviewed configuration, immutable source, and owned inputs for the intended site. Placeholders are deliberate.

nf-gtd-hpc-test review-collect --run-id RUN_ID
nf-gtd-hpc-test logs --run-id RUN_ID --tail 200

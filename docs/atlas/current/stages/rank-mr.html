Documentation / Workflow stage
Stage 04

Rank candidates and run the one-copy screen

Derive and retain every candidate-specific Matthews copy alternative, but search exactly one copy in every initial Molecular Replacement task.

Current maturity: local repair implemented; complete gate, CI, and fresh fixed-HPC screen pending

Visible limitation. No configured copy ceiling, joint-copy mode, or four-copy admission filter is part of the active initial screen.

Purpose

Narrow the candidate space into reviewable one-copy A seeds while preserving expected-copy alternatives, raw evidence, resources, and deferred reasons.

Inputs

  • Protein identities from the supplied list and their prepared models
  • Qualified diffraction selection
  • Workflow-derived PSORTb and DeepTMHMM localisation evidence
  • Optional user-provided molecular-weight evidence bound at the beginning of the analysis

Outputs

  • Candidate funnel and retained/deferred inventory
  • Resolution-conditioned Matthews solvent density and soft empirical ASU-copy prior
  • Independent Matthews and MR ranks with visible discordance
  • One-copy resource plans
  • Per-hypothesis Phaser commands, placements, scores, and status records

Decisions and statuses

  • Derive the complete copy range independently from each candidate's sequence mass, ASU volume, and solvent bounds
  • Use empirical ASU-copy frequency only as a soft weight; never filter a possible state because its prior is low or zero
  • Search exactly one copy in every initial task
  • Add copies only sequentially after explicit A approval
  • Apply the 25-hypothesis limit independently to each crystal
  • Keep Matthews and MR ranks separate
  • Continue sibling hypotheses after candidate-specific scientific failure

Claim and failure boundaries

  • SDS-PAGE mass is an apparent monomer prior, never ASU total mass
  • Expected copy count and empirical copy frequency are priors, not observed support
  • The Matthews score is not an identity probability
  • A placement is search evidence until reviewed
  • Rfree is not a high-throughput screening objective
Run commands and implementation links

Use commands only with the reviewed configuration, immutable source, and owned inputs for the intended site. Placeholders are deliberate.

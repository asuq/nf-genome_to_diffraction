Stage 04

Rank candidates and test Molecular Replacement hypotheses

For each first-component candidate, use Matthews analysis to retain physically plausible copy counts from 1 through 4, then directly run one joint Molecular Replacement hypothesis per retained count.

Current maturity: locally tested

Visible limitation. The scientific path is implemented, but broad fixed-profile qualification is still incomplete.

Purpose

Narrow the candidate and copy-count space into reviewable first-component solutions while preserving all raw evidence and deferred reasons.

Inputs

  • Protein identities from the supplied list and their prepared models
  • Qualified diffraction selection
  • Workflow-derived PSORTb and DeepTMHMM localisation evidence
  • Optional user-provided molecular-weight evidence bound at the beginning of the analysis

Outputs

  • Candidate funnel and retained/deferred inventory
  • Matthews priors for 1 through 4 copies
  • Per-hypothesis Phaser commands, placements, scores, and status records

Decisions and statuses

  • Preserve physically possible 1-, 2-, 3-, and 4-copy alternatives
  • Run each retained copy count as a direct joint hypothesis
  • Use sequential same-component addition only as rescue
  • Apply the 25-attempt limit across candidates and copy counts
  • Treat rank and Matthews probability as priors
  • Continue sibling hypotheses after candidate-specific scientific failure

Claim and failure boundaries

  • SDS-PAGE mass is an apparent monomer prior, never ASU total mass
  • A placement is search evidence until reviewed
  • Rfree is not a high-throughput screening objective
Run commands and implementation links

Use commands only with the reviewed configuration, immutable source, and owned inputs for the intended site. Placeholders are deliberate.

pixi run --locked phase3-multicrystal-stub
nf-gtd-hpc-test status --run-id RUN_ID

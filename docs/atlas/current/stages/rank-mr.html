Scientist / Operator / Workflow stage
Stage 04

Rank candidates and test MR hypotheses

Order candidates with explicit priors, enumerate physically plausible copy counts, and run independent first-copy Phaser attempts.

Current maturity: locally tested

Visible limitation. The scientific path is implemented, but broad fixed-profile qualification is still incomplete.

Purpose

Narrow a large candidate/model space into reviewable placement hypotheses while preserving all raw evidence and deferred reasons.

Inputs

  • Catalogue identities and prepared model registry
  • Qualified diffraction selection
  • Localisation and gel evidence when supplied

Outputs

  • Candidate funnel and retained/deferred inventory
  • Matthews copy-count priors
  • Per-hypothesis Phaser commands, placements, scores, and status records

Decisions and statuses

  • Retain multiple plausible copy counts
  • Treat rank and Matthews probability as priors
  • Continue sibling hypotheses after candidate-specific scientific failure

Claim and failure boundaries

  • SDS-PAGE mass is an apparent monomer prior, never ASU total mass
  • A placement is search evidence until reviewed
  • Rfree is not a high-throughput screening objective
Operator commands and implementation links

Use commands only with the reviewed configuration, immutable source, and owned inputs for the intended site. Placeholders are deliberate.

pixi run --locked phase3-multicrystal-stub

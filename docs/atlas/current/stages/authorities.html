Stage 01

Authoritative inputs

Bind one trusted protein catalogue and the diffraction datasets to immutable identities before any search begins.

Current maturity: implemented

Visible limitation. Input authority is fail-closed; a changed byte creates a different identity.

Purpose

Establish which catalogue, annotation source, sequences, MTZ files, and operator declarations are allowed to support the analysis.

Inputs

  • One imported protein catalogue from one annotation source
  • Diffraction MTZ files and crystal identifiers
  • Versioned run configuration and database manifests

Outputs

  • Checksum-bound catalogue and sequence-equivalence groups
  • Owned diffraction identities
  • Run and provenance records used by every later stage

Decisions and statuses

  • Reject mixed annotation sources
  • Stop on a missing, changed, duplicated, or malformed authority
  • Preserve every compatible locus when sequences are identical

Claim and failure boundaries

  • External structure providers cannot create a reportable identity
  • Missing evidence is not converted into a negative observation
  • A catalogue import is trusted; taxonomy and gene prediction are out of scope
Operator commands and implementation links

Use commands only with the reviewed configuration, immutable source, and owned inputs for the intended site. Placeholders are deliberate.

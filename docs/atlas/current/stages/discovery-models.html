Documentation / Workflow stage
Stage 03

Discovery and model preparation

Search for three-dimensional models while keeping every proposed identity tied to a protein in the supplied list.

Current maturity: HPC-qualified

Visible limitation. Individual providers and profiles have different qualification evidence; no-hit remains scientifically valid.

Purpose

Create a complete eligible model registry and a bounded prepared search set from experimental and predicted structures.

Inputs

  • Groups of identical sequences from the supplied protein list
  • Versioned local PDB and ProstT5/Foldseek resources
  • Optional remote ESM Atlas consent and cache

Outputs

  • Provider plans, hits, no-hits, and mapping gaps
  • All-eligible model registry
  • Prepared coordinate models with uncertainty and source records

Decisions and statuses

  • Keep provider no-hit separate from execution failure
  • Require explicit consent before remote sequence submission
  • Retain eligible models outside the initial search cap for later composition search

Claim and failure boundaries

  • Predicted models are hypotheses, not experimental evidence
  • Normal runs never silently prepare databases
  • Remote responses are versioned and cached by sequence digest
Run commands and implementation links

Use commands only with the reviewed configuration, immutable source, and owned inputs for the intended site. Placeholders are deliberate.

nf-gtd-hpc-test database-readiness
pixi run --locked phase3-foldseek-batch-stub

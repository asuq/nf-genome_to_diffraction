## Cache and package reconciliation

The integrated audit updated the semantic identities used by first/additional
copy, fixed-partner and multi-fixed searches; complete-inventory funnels;
MR review and reviewed reopening; composition execution/depth outcomes;
copy assessment and continuation staging; predicted-model processing and
refinement; and production M6 preparation, selection and case/run evidence.

Two indirect consumers of the shared physical-status function also received
new identities: `catalogue-partner-plan-v3-nonnegative-solvent` and
`phase3-component-candidate-generation-v3-nonnegative-solvent`. Their content
identities can no longer label the old solvent-window exclusion semantics as
current. Historical M6 readers keep their explicit archived formats, while
active wrappers, stubs and collectors require current v3 M6 records.

The installed collector's data model and terminal Raven file reader live in
the public package; SSH, scheduler and process-control implementation stays
inside the repository-only HPC package. The offline wheel probe exercises
this import boundary as well as the single console entry point, packaged
schemas and version parity.

The atlas was regenerated from the integrated source: 172 application Python
modules, 2,430 Python symbols, 157 test modules, 76 Nextflow files with 129
declarations, ten JSON schemas and seven reviewed shell files. These are source
inventory counts, not scientific acceptance metrics. Immutable v0.2 release
history is preserved.

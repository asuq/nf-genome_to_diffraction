# Historical Raven identification evidence

The operator-crystal identification and supplied exact-model programme was
cancelled on 2026-09-09. The user accepted all three candidate assessments after
external supervisor confirmation. Preserve that confirmation separately from
computed MR, refinement and sequence evidence. Do not restart the cancelled
cohort or require it before the approved RF/M6 development.

The historical route reused the identification archive, preparation/Phaser
adapters, Nextflow graph and assessment policy. A detached Raven login process
owned independent Slurm children. Its host, PID, boot identity and kernel start
ticks were recorded separately from scheduler job identities. All managed
storage was under the approved `/ptmp` project root; the original manifests,
source snapshots, launch records, logs and collected assessments remain
read-only evidence.

The parallel Raven command, transport and launch modules have been retired from
the active source. Their historical implementations remain recoverable from Git
and the frozen remote source snapshots. This retirement deletes no remote run,
scientific output or collected evidence, and does not convert old records into
new managed-run records.

All supported new Raven work uses the original `nf-gtd-hpc-test` application and
the [common fixed-profile feedback loop](hpc-feedback-loop.md). That route
preserves immutable deployment, explicit login-versus-Slurm controller identity,
owned monitoring and bounded collection. Current native M6 qualification is
independent of the accepted identification assessments; neither establishes the
other, and neither authorises new AF01 GPU work.
